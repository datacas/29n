Cómo usarlo: lee cada bloque. Si el valor te parece bien, no hagas nada. Si no, anota el código (por ejemplo `Q027 · Vox`) y el valor que crees correcto (−2, −1, 0, +1, +2), o «quitar» si la cita no responde a la pregunta.
